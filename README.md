# 栖居 · 家具空间预览

响应式家具试摆与 AI 空间效果图网页，支持电脑和手机。

- 网站：https://zhangliang2026999.github.io/my-website/
- GitHub Pages 来源：`main` 分支的 `/docs` 目录。
- 产品分类：餐边柜、餐桌、茶几、餐椅；现有两款餐边柜，其余等待添加。
- 当前尚未实现产品管理后台。

## 部署结构

`docs/` 是 GitHub Pages 实际发布的静态网页。`public/` 是前端源码，`worker/` 为服务端接口，`scripts/` 为本地开发和构建工具。

GitHub Pages 不能运行生成接口。当前 `docs/api-config.js` 连接现有 Cloudflare Quick Tunnel 后端；该后端需要本地电脑、网页服务和隧道持续运行。隧道关闭后，静态页面仍可浏览和试摆，但不能调用 AI 生成。更换后端时修改该配置文件，并在后端仅允许本站来源的跨域请求。

API 密钥仅配置在服务端环境变量 `XJJUHE_API_KEY`，禁止写入公开文件或前端配置。仓库不包含 GitHub 访问令牌或生成服务密钥。

## 本地开发

Node.js 22+，无需 npm 依赖：

```sh
npm run build
npm test
npm run dev
```

开发服务会从环境变量或隐藏的标准输入读取生成密钥。默认地址为 `http://127.0.0.1:4178/`。

## 图片与生成

客户明确勾选图片用途后，点击生成会把空间图、所选家具图和摆放示意发送至 xjjuhe.site。密钥由服务端添加，浏览器通过后端查询任务与获取结果图。AI 效果仅供搭配参考，实际尺寸、材质和款式需与商家确认。

家具图片来自项目所有者提供的实拍素材，名称为展示用名。空间示例来源于 Unsplash。
